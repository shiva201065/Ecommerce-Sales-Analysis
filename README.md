# E-Commerce Sales Analysis using MySQL

## Project Overview
This project analyzes e-commerce sales data using MySQL. The database contains order details such as customer name, product name, category, quantity, price, and order date.

## Database Used
ecommerce_db

## Table Used
orders

## SQL Concepts Applied
- SELECT
- WHERE
- GROUP BY
- ORDER BY
- COUNT()
- SUM()
- AVG()
- Aggregate Functions

## Analysis Performed
1. Total Revenue Analysis
2. Total Orders Analysis
3. Top Customers Analysis
4. Category-wise Revenue Analysis
5. Monthly Sales Trend Analysis

## Key Insights
- Identified top-spending customers.
- Calculated total business revenue.
- Analyzed category performance.
- Generated sales insights using SQL queries.
